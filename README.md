# 📝 To-Do List Web App

A simple and responsive **To-Do List Web Application** built using **HTML, CSS, and JavaScript**.  
This project helps users create, manage, and organize their daily tasks through a clean and easy-to-use interface.

## 🚀 Live Demo

👉 [View Live Project](https://rishabh-raj68.github.io/To-Do-List/)

## 📌 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 Display all added tasks
- ⚡ Fast and interactive user interface
- 📱 Responsive design
- 🎨 Clean and simple UI

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and DOM manipulation

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/rishabh-raj68/To-Do-List.git
```

2. Open the project folder:

```bash
cd To-Do-List
```

3. Open `index.html` in your browser.

That's it! 🎉
